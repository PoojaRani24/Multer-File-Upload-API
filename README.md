# 📁 Multer File Upload API

A simple Node.js project demonstrating **file uploads with Multer** — from receiving `multipart/form-data` to storing uploaded files on the server.

## ✨ What it demonstrates

* 📤 Upload files through an API
* 🧩 Handle `multipart/form-data` with **Multer**
* 📁 Store uploaded files on the server
* 🔒 Configure file upload destinations and filenames
* ⚡ Build a lightweight file-upload workflow with Node.js

## 🛠️ Tech Stack

**Node.js · Express · Multer**

## 🚀 Getting Started

```bash
git clone https://github.com/PoojaRani24/File-Upload-using-Multer.git
cd File-Upload-using-Multer
npm install
npm start
```

Then send a `multipart/form-data` request with your file to the upload endpoint.

## 💡 Why Multer?

[Multer](https://github.com/expressjs/multer) is a Node.js middleware for handling `multipart/form-data`, making it straightforward to process file uploads in Express applications.
